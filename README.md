# HobbyAI | Discover Your Next Passion ✨

HobbyAI is an **AI-powered skill-based recommendation system** designed to help users find their next hobby through a data-driven approach. By analyzing user-specific constraints—such as time, budget, and social preferences—HobbyAI provides personalized matches and actionable roadmaps to get started.

## 🚀 Key Features

- **Adaptive 10-Question Quiz**: Assesses your profile across 6 key dimensions:
  - ⏱️ **Time**: Availability per week.
  - 💰 **Budget**: Initial and ongoing investment.
  - 🏋️ **Physical**: Desired activity level.
  - 🤝 **Social**: Preference for solitude vs. community.
  - 🎨 **Creativity**: Desire for self-expression or creation.
  - ⚙️ **Technical**: Complexity and tools required.
- **Smart Recommendation Engine**: Uses **cosine similarity** for vector-based matching and **weighted popularity** scoring to suggest the top 5 hobbies.
- **Personality Detection**: Automatically categorizes your profile into archetypes (e.g., "Explorer", "Tech Wizard") with achievement badges.
- **Actionable Roadmaps**: Each recommendation includes a clear 90-day plan (Days 30/60/90) for mastery.
- **Starter Kits & Resources**: Comprehensive list of tools and learning materials for every suggested hobby.
- **Modern & Premium UI**: Features a glassmorphic design, smooth animations, and full **Dark/Light Mode** support.

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, Semantic Structure.
- **Styling**: Vanilla CSS3, Custom Properties (Variables), Flexbox/Grid, Keyframe Animations.
- **Logic**: Vanilla JavaScript (ES6+), LocalStorage for state persistence.
- **Assets**: Embedded PDFs for System Architecture and Workflow.
